# Отчёт за неделю

## Результат

Собрано готовое desktop-приложение Pixora на Python и PySide6. Реализован
полный цикл локальной обработки изображения: загрузка, предпросмотр, настройка,
фоновая обработка, сравнение результата, сохранение и запись в историю SQLite.

## Выполнено

- реализованы resize, conversion, compression, rotate и flip через Pillow;
- применены Strategy, Factory, Repository и сигналы/слоты Qt;
- обработка перенесена в `QThreadPool`;
- добавлены валидация, уведомления и обработка ошибок;
- создана история операций с очисткой и открытием сохранённого файла;
- подготовлен адаптивный тёмный интерфейс;
- написано 60 автоматических тестов;
- добавлено Docker-окружение для тестового запуска;
- подготовлены README и воспроизводимые скриншоты.

## Сложности и решения

- Чтобы GUI не зависал, Pillow pipeline выполняется через `QRunnable`, а
  результат возвращается сигналами Qt.
- Чтобы избежать повторной потери качества, результат кодируется один раз в
  worker и при сохранении записывается без повторного сжатия.
- Для окна высотой 640 px настройки помещены в стилизованную область прокрутки.
- Повреждённые изображения, неверные расширения, файлы больше 20 МБ и опасные
  размеры отсекаются до обработки.
