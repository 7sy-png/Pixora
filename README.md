# Pixora

Pixora — нативное desktop-приложение на Python для локальной обработки изображений. Оно позволит загружать изображения через Drag & Drop или проводник, менять размер и формат, настраивать качество, поворачивать и отражать изображения, а также сохранять историю операций.

## Стек

- Python 3.12+
- PySide6
- Pillow
- SQLite
- pytest

## Текущее состояние

Подготовлена базовая структура проекта и каркас главного окна PySide6. Интерфейс использует отдельную тёмную тему, а зона предпросмотра принимает локальные изображения JPG, PNG и WEBP через Drag & Drop или системный диалог выбора файла. Функциональность будет добавляться небольшими законченными этапами с отдельными коммитами.

## Подготовка окружения

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Запуск

```powershell
python main.py
```

## Ближайшие этапы

1. Предпросмотр изображения.
2. Информация о загруженном файле.
3. Модели данных изображения и настроек.
4. Панель изменения размера.
5. Автоматическое сохранение пропорций.

## Структура проекта

```text
app/             исходный код приложения
  ui/            окна и виджеты PySide6
  processors/    стратегии обработки изображений
  services/      сценарии и бизнес-логика
  repositories/  доступ к истории операций
  workers/       фоновые задачи Qt
  models/        модели данных
  database/      настройка SQLite
  utils/         общие вспомогательные функции
  resources/     стили и иконки
tests/           автоматические тесты
data/            локальные данные приложения
reports/         недельные планы и отчёты
```
