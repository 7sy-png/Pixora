# Pixora

Pixora — нативное desktop-приложение на Python для локальной обработки изображений. Оно позволит загружать изображения через Drag & Drop или проводник, менять размер и формат, настраивать качество, поворачивать и отражать изображения, а также сохранять историю операций.

## Стек

- Python 3.12+
- PySide6
- Pillow
- SQLite
- pytest

## Текущее состояние

Подготовлена базовая структура проекта и каркас главного окна PySide6. На панели настроек доступны размеры, формат результата и качество JPEG/WEBP от 1 до 100. Для PNG настройка качества автоматически блокируется.

## Подготовка окружения

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Запуск

```powershell
python main.py
```

## Ближайшие этапы

1. Сервис обработки изображений.
2. Фоновая обработка.
3. Состояние загрузки.
4. Панель результата.
5. Сохранение результата.

## Структура проекта

```text
app/             исходный код приложения
  ui/            окна и виджеты PySide6
  processors/    стратегии обработки изображений
  services/      сценарии и бизнес-логика
  repositories/  доступ к истории операций
  workers/       фоновые задачи Qt
  models/        модели данных
  database/      настройка SQLite
  utils/         общие вспомогательные функции
  resources/     стили и иконки
tests/           автоматические тесты
data/            локальные данные приложения
reports/         недельные планы и отчёты
```
