# Pixora

Pixora — нативное desktop-приложение на Python для локальной обработки изображений. Оно позволит загружать изображения через Drag & Drop или проводник, менять размер и формат, настраивать качество, поворачивать и отражать изображения, а также сохранять историю операций.

## Стек

- Python 3.12+
- PySide6
- Pillow
- SQLite
- pytest

## Текущее состояние

Подготовлена базовая структура проекта и каркас главного окна PySide6. Изображения JPG, PNG и WEBP можно выбрать через Drag & Drop или системный диалог. Адаптивный preview сохраняет пропорции, а данные изображения и параметры обработки представлены отдельными dataclass-моделями.

## Подготовка окружения

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Запуск

```powershell
python main.py
```

## Ближайшие этапы

1. Панель изменения размера.
2. Автоматическое сохранение пропорций.
3. Базовый интерфейс обработчиков.
4. Изменение размера изображения.
5. Фабрика обработчиков.

## Структура проекта

```text
app/             исходный код приложения
  ui/            окна и виджеты PySide6
  processors/    стратегии обработки изображений
  services/      сценарии и бизнес-логика
  repositories/  доступ к истории операций
  workers/       фоновые задачи Qt
  models/        модели данных
  database/      настройка SQLite
  utils/         общие вспомогательные функции
  resources/     стили и иконки
tests/           автоматические тесты
data/            локальные данные приложения
reports/         недельные планы и отчёты
```
